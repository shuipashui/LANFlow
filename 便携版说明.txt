LANFlow Windows 便携版
============================

1. 双击“启动 LANFlow.cmd”。
2. 浏览器会自动打开管理页面。
3. 同一 Wi-Fi 或热点内的其他设备，打开窗口中显示的 Network 地址即可访问。
4. 把希望长期共享的文件放进 data\shared 文件夹。
5. 别人发送到主机收件箱的文件位于 data\inbox 文件夹。
6. 保持黑色服务窗口开启；可在电脑网页右上角点击“结束服务”。

安全建议：
- Windows 防火墙询问时，仅允许“专用网络”。
- 不要在机场、商场等公共 Wi-Fi 中无口令运行。
- 整个文件夹可以复制到其他 Windows x64 电脑，无需安装 Node.js。
